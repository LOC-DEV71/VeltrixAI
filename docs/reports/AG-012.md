# Báo cáo Nhiệm vụ AG-012: Tích hợp API Auth & Workspace CRUD

## 1. Cấu hình Axios & Cơ chế Bảo mật Cookie / CSRF
- Khởi tạo file `src/api.ts` quản lý cấu hình axios chung. Đã bật `withCredentials: true` để trình duyệt tự động đính kèm cookie HttpOnly vào mọi request gửi lên server.
- **CSRF Token Logic**:
  - Interceptor tự động bắt giá trị `x-csrf-token` từ header của response (do backend sinh ra từ `csrfMiddleware`) và lưu vào biến toàn cục tĩnh.
  - Các request mang tính thay đổi trạng thái (`POST`, `PUT`, `DELETE`, `PATCH`) sẽ được Interceptor tự động tiêm `x-csrf-token` vào request header.

## 2. Refresh Token tự động (401 Interceptor)
- Đã triển khai cơ chế **Axios Response Interceptor** thông minh để xử lý lỗi 401 Unauthorized:
  - Khi token hết hạn (401), request gốc sẽ bị tạm ngưng (đưa vào queue).
  - Tự động gọi API `POST /api/v1/auth/refresh` bằng Refresh Token (cũng lưu trong Cookie).
  - Nếu refresh thành công, các request bị queue sẽ được retry với Access Token mới.
  - Tránh spam gọi refresh nhiều lần liên tiếp khi có nhiều request đồng thời (biến cờ `isRefreshing`).
  - Nếu token refresh thất bại (401/409), hiển thị Toast lỗi và force redirect user về `/login`.

## 3. UI Tạm thời (Login) & Auth Provider
- Dựng tạm trang `/login` cho phép gọi API tạo OTP giả lập và Verify OTP.
- Xây dựng `AuthContext` (Provider) để theo dõi state user hiện tại (fetch `/api/v1/auth/me` lúc mở app).
- Áp dụng `ProtectedRoute` wrap toàn bộ App Layout: Nếu chưa có user -> đá về `/login`.

## 4. Tích hợp Workspace & Create Content
- **WorkspacePage**: Chuyển đổi giao diện tĩnh ST-002 thành giao diện động, map dữ liệu `projects` thực tế từ API `GET /api/projects`. Tích hợp đầy đủ các trạng thái "Đang tải", "Có dữ liệu" và Empty State "Thư mục trống".
- **Sidebar**:
  - Gắn sự kiện `onClick` vào nút "+ Tạo nội dung".
  - Khi nhấn, hệ thống sẽ gọi `api.post('/contents')` để khởi tạo nội dung mới, sau đó chuyển hướng (`navigate`) user vào màn hình Studio theo ID vừa tạo.
