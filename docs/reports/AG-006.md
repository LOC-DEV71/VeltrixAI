# Báo cáo Nhiệm vụ AG-006: Triển khai CRUD API cho Workspace, Project và Content

## 1. Khởi tạo dữ liệu ngầm định (Default Data)
- Cập nhật luồng đăng ký/đăng nhập trong `AuthController.ts` (`googleLogin` và `verifyOtp`).
- Bổ sung logic tự động tạo 1 Workspace (`"My Workspace"`) và 1 Project mặc định (`"Dự án đầu tiên"`) khi một User mới hoàn thành quá trình khởi tạo tài khoản.

## 2. Xây dựng Schema Data Model (v0.3)
- Triển khai thành công các schema MongoDB dựa trên thiết kế `DATA_MODEL.md` (v0.3):
  - `Workspace` (models/Workspace.ts)
  - `Project` (models/Project.ts)
  - `Content` (models/Content.ts)

## 3. Phát triển RESTful API
- Triển khai `ProjectController` và `ContentController` với các endpoints:
  - `GET /api/projects`: Trích xuất danh sách dự án của user hiện tại, có hỗ trợ phân trang.
  - `POST /api/contents`: Khởi tạo bản nháp nội dung mới liên kết với `projectId`.
  - `GET /api/contents/:id`: Truy xuất chi tiết một bản nháp.
  - `PUT /api/contents/:id`: Cập nhật nội dung văn bản (`rawText`) và tự động tăng revision.
- Tất cả route được gắn vào Router tổng và được đăng ký tại `src/index.ts`.

## 4. Bảo mật & Phân quyền
- Toàn bộ endpoints trên đã được bảo vệ qua lớp `authMiddleware` (yêu cầu Access Token hợp lệ).
- Cài đặt thêm các lớp kiểm tra chủ quyền chéo (Ownership Checking): 
  - Hệ thống truy xuất `workspaceId` của Project và xác thực User đang request phải là `ownerId` của Workspace đó.
  - Trả về mã lỗi `403 FORBIDDEN` nếu User cố tình can thiệp vào Project hoặc Content của tài khoản khác.

## 5. Kết quả Integration Test (Supertest)
- Đã xây dựng bộ test hoàn chỉnh tại `tests/crud.test.ts`.
- Sử dụng `mongodb-memory-server` để giả lập database.
- Mô phỏng các requests bằng `supertest` kết nối trực tiếp với Express `app`.
- **Kết quả: Pass 100% (3/3 tests)**:
  - (1) GET `/api/projects` không có token trả về đúng mã 401 Unauthorized: **PASS**.
  - (2) GET `/api/projects` với token chính chủ trả về danh sách project: **PASS**.
  - (3) POST, GET, PUT `/api/contents` hoạt động hoàn hảo, chặn đứng hành vi lấy token User B ghi vào Project của User A bằng mã 403 Forbidden: **PASS**.
