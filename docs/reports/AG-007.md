# Báo cáo Nhiệm vụ AG-007: Xây dựng Foundation UI & Mock Pages (ST-001, ST-002)

## 1. Thiết lập Design System (DS-001 v0.1)
- Cấu hình TailwindCSS v4 tích hợp với Vite (`@tailwindcss/vite`).
- Thiết lập hệ thống Design Tokens đúng chuẩn tại `src/index.css`:
  - `bg-base`: `#F7F8FC`
  - `text-main`: `#172033`
  - `text-sub`: `#667085`
  - `primary`: `#4F46E5`
  - Typography: `Be Vietnam Pro`
- Xây dựng các Base UI Components: `Button`, `Input`, `Dropdown`, `Card` có khả năng tái sử dụng cao.

## 2. Layout & Router
- Khởi tạo React Router DOM với Layout chính (`AppLayout`).
- **Sidebar**: Cố định 224px bên trái. Tích hợp Header Logo `CA Creator AI`, nút tạo mới nổi bật, Navigation Menu và khối User Profile ở dưới cùng.
- **Header**: Cố định 64px bên trên. Tích hợp Breadcrumbs, thanh tìm kiếm (Search) và nút Thông báo (Bell).
- Vùng nội dung chính (`main`) sử dụng `flex-1 overflow-y-auto` đảm bảo content cuộn mượt mà mà không làm trôi Sidebar/Header.

## 3. Phát triển Màn hình (Mock UI)
### Màn hình Workspace (Dựa trên ST-002)
- Render danh sách dự án dưới dạng Grid.
- Card dự án hiển thị đầy đủ Trạng thái (Bản nháp, Đã sinh Audio) với màu sắc phân biệt rõ ràng.
- Xây dựng trạng thái rỗng (Empty State) bắt mắt khi chưa có dự án nào.

### Màn hình Text to Speech (Dựa trên ST-001)
- Layout phân mảnh chuyên nghiệp: Trái (Editor) - Phải (Cài đặt giọng).
- Khu vực Editor: Hỗ trợ textarea nhập văn bản.
- Khu vực Settings (320px): Dropdown chọn ngôn ngữ/giọng đọc, hiển thị Credit dự kiến và nút Tạo giọng đọc.
- Khu vực Lịch sử (Bottom): Khung hiển thị lịch sử file audio đã sinh.
