# Báo cáo Nhiệm vụ AG-010: Khởi tạo Giao diện "Giọng của tôi"

## 1. Tích hợp Route & Component Structure
- Khai báo Route `/voices` trên `App.tsx` và cấu hình trạng thái Active tương ứng trên Sidebar.
- Phân rã mã UI ST-005 thành cấu trúc thư mục Component tối ưu tại `src/pages/voices/`:
  - `SystemVoiceCard.tsx`: Dành cho danh sách giọng mẫu.
  - `CloneVoiceCard.tsx`: Dành cho các giọng do user upload tự custom.
  - `UpgradeBanner.tsx`: Hiển thị khối call-to-action yêu cầu nâng cấp gói.
  - `CloneVoiceModal.tsx`: Popup Form upload audio để huấn luyện AI.

## 2. Quản lý State & Mock UI Logic
- **Premium State (Toggle Button)**:
  - Tích hợp nút giả lập (Mock button) cho phép lập trình viên tự chuyển đổi qua lại giữa gói Free và Premium.
  - **Trạng thái Free (`isPremium = false`)**: Giấu giao diện quản lý Clone Voice, hiển thị `UpgradeBanner` thu hút với các quyền lợi nâng cấp.
  - **Trạng thái Premium (`isPremium = true`)**: Mở khóa UI, render danh sách `CloneVoiceCard` và nút "+ Thêm giọng Clone mới".

## 3. Clone Voice Modal (Popup Tương tác)
- Xây dựng component `CloneVoiceModal` hiển thị đè lên UI dưới dạng backdrop mờ (Overlay).
- Chứa form Input (Tên giọng), vùng Dropzone tải audio (chưa code API thật), và một Checkbox cam kết bản quyền.
- **Logic Validation tĩnh**: Nếu Checkbox "Cam kết bản quyền" không được chọn, nút "Bắt đầu Clone" sẽ tự động rơi vào trạng thái `disabled` (vô hiệu hóa, màu nhạt) để ngăn người dùng thao tác tiếp, thỏa mãn đúng requirement.
