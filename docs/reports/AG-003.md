# Báo cáo Nhiệm vụ AG-003: Chốt Data Model v0.2 và Contract Auth

## 1. Mục tiêu
Sửa các thiếu sót của thiết kế dữ liệu trước khi đi vào triển khai code nghiệp vụ. Cập nhật tài liệu, không viết code logic.

## 2. Các Tài liệu đã cập nhật
- **DATA_MODEL.md (v0.2)**: 
  - Khởi tạo đầy đủ hệ thống collection, index (Unique, Partial, TTL).
  - Tách bạch `wallets` và `credit_ledgers`, `jobs` và `outbox`.
  - Mở rộng cấu trúc hệ thống Sáng tạo (Thêm `workspaces`, `contents`, sửa cấu trúc `scenes` phân biệt thứ tự/nội dung với timeline video).
  - Định nghĩa rõ `media_assets` quản lý file tập trung và quyền sở hữu.
- **AUTH_AND_PERMISSIONS.md (v0.2)**: 
  - Quy tắc chuẩn hóa email, Google Identity login (chỉ map `sub`).
  - Giải thích cơ chế luồng "Chứng minh quyền sở hữu" nếu trùng email mà chưa liên kết.
  - Chi tiết Session (Token Family, Grace period) để phát hiện Refresh Token bị rò rỉ.
  - Tách biệt Roles (Admin) và Subscriptions (Tính năng khách hàng). 
  - Cập nhật chống lạm dụng Device ID, giữ lịch sử qua các tháng.
- **JOBS_AND_CREDITS.md (v0.2)**: 
  - Thêm ví dụ bắt buộc về `GRANT`, `RESERVE`, `SETTLE`, `FAILED` trong ví MongoDB bằng Integer.
  - Mô tả quy trình Transactional Outbox. Worker Idempotency. Trả lại Credit đúng nguồn.
- **API_CONTRACT.md (v0.2)**: 
  - Định nghĩa rõ endpoint login, OTP request/verify, refresh, logout, GET /me. 
  - Đưa chuẩn trả về HTTP codes và cơ chế bảo mật (SameSite, CSRF).
- **OPEN_QUESTIONS.md (v0.2)**: Cập nhật tinh gọn, lược bỏ phần DeviceID/Credit đã được chốt giải pháp.

## 3. Trạng thái Dependency
Phiên bản resolved thực tế của môi trường:
- Node.js: `v24.12.0`
- pnpm: `12.8.1`
- Python: Chưa có `3.11` (Bị BLOCKED, hiện tại máy là `3.14.4` không có wheel native cho Windows).
- MongoDB/Redis Local: Chưa có `docker` (Bị BLOCKED).

*Không có thêm code mới nào được thực thi trong AG-003, các kiểm tra runtime của nền tảng v0.1 vẫn duy trì PASS.*
